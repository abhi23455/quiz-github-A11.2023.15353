## Deskripsi

Repository ini berisi project aplikasi Poliklinik yang dikembangkan sebagai bagian dari tugas mata kuliah Bengkel Koding. Project ini menggunakan framework Laravel dan mencakup pengelolaan data pasien, poli, jadwal periksa, pendaftaran poli, pemeriksaan, obat, serta detail pemeriksaan. Aplikasi ini dirancang untuk memudahkan proses administrasi di lingkungan poliklinik mulai dari pendaftaran pasien sampai dengan pemberian resep obat.
